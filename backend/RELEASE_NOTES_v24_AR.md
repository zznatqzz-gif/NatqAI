# إصدار NatqAI v24

## تحسين موثوقية بناء Android APK

- أصبح فحص جاهزية عامل البناء يتحقق من تشغيل Gradle 8.7 فعلياً، وليس مجرد وجود الملف التنفيذي.
- يتحقق من Java 17 عبر تشغيل `java -version`.
- يتحقق من وجود Android SDK Platform 35 وملفات Android Build Tools 35 الأساسية (`aapt2` و`d8` و`zipalign`).
- يرفض عامل البناء طلب البناء إذا كانت بيئة الأدوات غير جاهزة، حتى عند تجاوز فحص الواجهة واستدعاء API مباشرة.
- يحتفظ بفحص صحة أرشيف المصدر قبل فحص البيئة حتى تظهر أخطاء الملفات غير الصالحة بشكل دقيق.

## التحقق

- 72 اختبار backend ناجح.
- فحوص صياغة Python وJavaScript ناجحة.
- لم يتم بناء APK حقيقي؛ يتطلب ذلك تشغيل الحاوية في بيئة تحتوي Android SDK وGradle وJDK 17.
