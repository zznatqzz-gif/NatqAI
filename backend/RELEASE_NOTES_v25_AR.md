# ملاحظات الإصدار v25

- جعل فحص جاهزية Android Builder يفشل إذا لم يكن سر المصادقة مضبوطاً، حتى لا تظهر الخدمة جاهزة بينما ترفض كل طلبات البناء.
- إضافة اختبار يغطي حالة غياب سر العامل.
- إضافة Docker HEALTHCHECK يعتمد `/ready` بدلاً من الاكتفاء بفحص HTTP العام.
- إضافة `backend/android_builder/railway.json` لإعداد فحص الجاهزية وسياسة إعادة التشغيل عند نشر العامل كخدمة مستقلة.
- إضافة دليل عربي لنشر العامل كخدمة Railway خاصة وربط `ANDROID_BUILDER_URL` و`ANDROID_BUILDER_TOKEN` دون كشف الأسرار.

لم يتم إنشاء أو نشر خدمة Railway ولم يتم استهلاك موارد مدفوعة. لم يتم بناء APK حقيقي في هذه البيئة؛ ذلك يتطلب نشر العامل وتشغيل Gradle/Android SDK فعلياً.
